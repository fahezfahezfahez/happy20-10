2. CHAY WEBSITE TREN MAY TINH

- Dam bao cac file nam trong cung mot thu muc.
- Kiem tra file nhac co ten dung la music.mp3.
- Nhan dup vao index.html de mo website.
- Neu nhac khong tu phat, bam nut BAT NHAC NEN.

Neu muon kiem tra gan voi moi truong website that,
ban co the mo thu muc bang VS Code va dung Live Server.

3. SUA LOI CHUC

Mo index.html bang VS Code.
Tim cac dong chu trong cac the h1, h2, p va sua
thanh loi chuc ban muon.

4. DOI NHAC

- Chon file MP3 ban co quyen su dung.
- Doi ten thanh music.mp3.
- Thay file music.mp3 cu bang file moi.
- Khong can sua script.js neu giu nguyen ten file.

5. DANG WEBSITE LEN GITHUB PAGES

- Dang nhap GitHub.
- Tao repository moi, vi du: qua-20-10-lop-910.
- Tai len index.html, style.css, script.js,
  music.mp3 va README.txt.
- Mo Settings > Pages.
- Chon Deploy from a branch.
- Chon nhanh main va thu muc /(root).
- Bam Save va cho GitHub xuat ban website.

GitHub se hien thi dia chi website sau khi xuat ban.
Ban co the gui duong dan do cho cac ban trong lop.

6. NEU WEBSITE BI LOI

- Kiem tra ten file co viet dung khong.
- Kiem tra style.css va script.js duoc lien ket
  trong index.html.
- Kiem tra file music.mp3 da duoc tai len GitHub.
- Neu sua code ma website chua cap nhat,
  hay tai lai trang va cho GitHub Pages xuat ban lai.
